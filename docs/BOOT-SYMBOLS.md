# Boot `.sndata` symbols, USA PS2

The verified boot ELF has a `.sndata` section at `0x01F0AD00`. Its first bytes
are another `SNR2` header, with **linked virtual addresses** in its tables,
unlike the level `.REL` modules' file offsets. The table contains 1,804
entries: one empty sentinel, **1,803 named symbols**, of which 1,317 point
inside the ELF's `.text` section. Others point to data, BSS, read-only data,
or outside any declared section. The ELF's `.reginfo` value for `$gp` is
`0x01F300F0`, agreeing with the `_gp` symbol in this table.

[`config/boot/symbols.tsv`](../config/boot/symbols.tsv) is generated by
[`tools/boot_symbols.py`](../tools/boot_symbols.py). Its `section` column
reports the **ELF section containing the recorded address**, not a function
classification. Labels inside `.text` are not necessarily function starts;
none carries a validated size or C match. The `kind` column preserves the
SNR2 number without assigning a meaning not yet demonstrated.

The boot table has `lib_main__FiPPc` with address zero. Every level `.REL`
exports that name with a nonzero module-relative offset, consistent with a
level-provided entry, though the loader's exact relocation and call path are
still to be checked. Across the level modules, 5,517 import entries use 289
distinct names; 288 occur in the boot table or another module's exports.
`FRONTEND.REL` refers twice to
`PAUSEMODE_GetCurrentPauseScreen__Fv`, which is absent by that exact name from
both tables. Its runtime resolution is an open question, not an assumed stub.

The catalogues are reproducible locally from the pinned input:

```sh
python tools/boot_symbols.py inspect baserom/SCUS_976.15
python tools/boot_symbols.py catalogue baserom/SCUS_976.15
python tools/boot_symbols.py catalogue baserom/SCUS_976.15 --write
python tools/rel.py inspect baserom/SCUS_976.15.iso --boot baserom/SCUS_976.15
```
